# interlatent

A place to test the interlatent services.

Nothing is here yet. Notes, scripts and results from the tests will go in this folder.

## Where things go

- Code and notes: here, in Git.
- Anything large (downloads, model weights, outputs over ~1 GB): `/mnt/fast/lilly/interlatent/`,
  linked in here if a script needs it nearby. Large files are ignored by Git (see `.gitignore`).
- Secrets (API keys, tokens): a local `.env` file, never committed.
